# newids.github.io

- 최근 작업: [BTS Key](https://newids.github.io/bts-key-imac/) · [iMac 실습 환경 자동 설정](https://newids.github.io/imac-setup/)
- e-book: [미션 파이썬](https://newids.github.io/python4e1/) · [JavaScript 개발자를 위한 Python](https://newids.github.io/python4js/) · [AICE Associate 딥러닝 실전 교본](https://newids.github.io/dl4aice/)
- Codyssey 미션: [B1-1 포트폴리오](https://newids.github.io/codyssey-b1-1/) · [B1-2 React](https://codyssey-b1-2-react.vercel.app) · [E1-2 파이썬 퀴즈](https://newids.github.io/codyssey-e1-2/) · [E2-1 아이디어톤](https://newids.github.io/codyssey-e2-1/)
- 도구: [GEN·QR](https://newids.github.io/gen-qr/) · [pdf2md](https://newids.github.io/pdf2md/) · [pdf2img](https://pdf2img-one.vercel.app) · [세벌식 최종 자판](https://newids.github.io/sebeolsik-final-keyboard/)
- iMac 실습 환경 설정: `curl -fsSL newids.github.io/mac | sh` (세벌식 최종은 `sh -s -- han3final`)
- 개인용 설정: `curl -fsSL newids.github.io/iMac4newid | sh`
